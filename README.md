# 별숲 모험단

한국어로 즐기는 오리지널 2D 액션 RPG 프로토타입입니다. 익숙한 판타지 RPG의 탐험·성장 감성과 모바일 아레나 게임의 직관적인 조작에서 영감을 받았으며, 독자적인 세계와 캐릭터로 구성했습니다.

## 실행하기

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 설치나 빌드 도구가 필요하지 않습니다.

## 조작

- PC: `WASD` 또는 방향키로 이동, 마우스 클릭 또는 `스페이스`로 공격, `Q`로 별빛 파동, `E`로 물약 사용
- 모바일: 왼쪽 가상 스틱으로 이동, 오른쪽 공격 버튼으로 공격, `별빛`과 `물약` 버튼으로 기술 사용

적을 처치해 경험치를 모으고 레벨을 올려 보세요.
